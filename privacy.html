最終更新: 2026-11-04

読み取るデータ

fitbit_woz は、利用者本人が許可した範囲で、Google Health API から睡眠、活動とフィットネス、健康の計測値(体重など)を読み取り専用で取得します。

使い方

取得したデータは、利用者本人の家庭用ダッシュボードに表示するためだけに使います。広告、販売、第三者への提供、機械学習の学習には使いません。

保存

データと認可のトークンは、利用者本人が管理する端末にのみ保存し、外部のサーバーへ送りません。

削除と取り消し

利用者は Google アカウントの「サードパーティのアクセス」からいつでも許可を取り消せます。取り消すと、以後のデータの取得は止まります。

Google API から受け取った情報の使用と他のアプリへの転送は、Google API Services User Data Policy(限定使用の要件を含む)に従います。
